IPv4 Parser Test Cases

VALID ADDRESSES

1. Basic valid IPv4 address
Input: 192.168.1.1
Expected: Extracted IPv4 address: 192.168.1.1 (decimal value: 3232235777, port: none)

2. Minimum IPv4 address
Input: 0.0.0.0
Expected: Extracted IPv4 address: 0.0.0.0 (decimal value: 0, port: none)

3. Maximum IPv4 address
Input: 255.255.255.255
Expected: Extracted IPv4 address: 255.255.255.255 (decimal value: 4294967295, port: none)

4. Valid address with port
Input: 10.0.0.255:8080
Expected: Extracted IPv4 address: 10.0.0.255 (decimal value: 167772415, port: 8080)

5. Maximum valid port
Input: 255.255.255.255:65535
Expected: Extracted IPv4 address: 255.255.255.255 (decimal value: 4294967295, port: 65535)

6. Minimum valid port
Input: 1.2.3.4:0
Expected: Extracted IPv4 address: 1.2.3.4 (decimal value: 16909060, port: 0)

7. Address surrounded by text
Input: hello192.168.1.1world
Expected: Extracted IPv4 address: 192.168.1.1 (decimal value: 3232235777, port: none)

8. Address with port surrounded by text
Input: server=10.0.0.255:8080end
Expected: Extracted IPv4 address: 10.0.0.255 (decimal value: 167772415, port: 8080)

9. Garbage character separates invalid beginning from valid address
Input: 192a168.1.1.1
Expected: Extracted IPv4 address: 168.1.1.1 (decimal value: 2818638081, port: none)
